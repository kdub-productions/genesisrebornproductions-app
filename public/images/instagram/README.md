# Instagram Mock Images

This directory contains mock images for the Instagram feed when the API key is not available.

Place your Instagram images in this directory with the following naming convention:
- post1.jpg
- post2.jpg
- post3.jpg
- post4.jpg
- post5.jpg
- post6.jpg

These images will be displayed in the Instagram section of the social media page when the Instagram API key is not available.

To update the content displayed with these images, edit the `mockSocialMediaData.ts` file in the `src/utils` directory.
